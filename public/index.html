Server-side analytics, no Google scripts in the browser

This page loads no third-party code. After consent, events go to /api/metrics on the same host, and the Worker sets an HttpOnly first-party cookie that Safari ITP does not cap at 7 days.

Analytics consent: unknown

How to verify

  1. Open DevTools → Network and accept analytics in the banner.
  2. You should see POST /api/metrics with Set-Cookie: __av_cid=…; HttpOnly in the response, and no requests to google* domains.
  3. Without consent the endpoint returns 204 without Set-Cookie.
  4. With GA_DEBUG=true the terminal running wrangler dev shows GA4 validation messages.
